# Job Portal Web Application 🚀

A full-stack Job Portal application where users can register, login, add jobs, manage jobs, save jobs, and explore opportunities with sorting features.

## 🌐 Live Demo

Frontend:
https://job-portal-1-hmnb.onrender.com

Backend:
https://job-portal-weft.onrender.com


## ✨ Features

- User Registration and Login
- JWT Authentication
- Protected Dashboard
- Add New Jobs
- View Available Jobs
- Edit Jobs
- Delete Jobs
- Save Jobs
- Apply Now Feature
- Job Sorting:
  - Location based sorting
  - Salary Low to High
  - Salary High to Low
  - Company A-Z sorting
- Dashboard Analytics:
  - Total Jobs
  - Total Companies
  - Total Locations
