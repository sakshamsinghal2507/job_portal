# Job Portal Full Stack Project

## 📌 Description
A full stack Job Portal web application where users can register, login, view jobs, and post jobs.

## ⚙️ Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MySQL
- Authentication: JWT

## 🚀 Features
- User Registration & Login
- JWT Authentication
- Add Jobs
- View Jobs
- Dashboard
- Protected Routes
